## Run the Program

### Server Side:
Do:
```bash
gcc *.c -o main
```

then:

```bash
./main
```


### Client

open another terminal or go the web browser
#### Terminal
do:

For GET requests:
```bash
curl http://localhost:8080/<file name>
```

For HEAD requests:
```bash
curl -I http://localhost:8080/<file name>
```
### Web Browser

put the url link:
```bash
http://localhost:8080/<file name>
```
